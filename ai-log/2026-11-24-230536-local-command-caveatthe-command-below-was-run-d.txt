  三、陷阱怎麼處理

  陷阱 1：型別要嚴格

  我先查了實際用到的版本：Spring Boot 4.2.0、Jackson
  tools.jackson.core:jackson-databind:3.1.8。

  - 怎麼關掉自動轉換：Jackson 3 的「字串轉數字」不是用 DeserializationFeature
    這類開關控制，要用 coercion config（型別轉換規則）。spring.jackson.*
    屬性設定不到這一塊，所以要寫 JsonMapperBuilderCustomizer bean，在裡面用
    withCoercionConfig(...) 設定：
    - 整數欄位（LogicalType.Integer）：遇到字串、浮點數、布林值 → 失敗。1.5 和
      1.0 都回 400
    - 小數欄位（LogicalType.Float，BigDecimal 屬於這類）：遇到字串、布林值 →
      失敗；遇到整數 → 接受，所以 1000 可以
    - 文字欄位（LogicalType.Textual）：遇到數字、布林值 → 失敗，所以 "code": 
      2330 回 400
  - 我不確定的一點：Jackson 3 的 String 轉換是否完全照 Textual 的 coercion
    規則。我會先寫測試確認；如果不行，改成只對 code 欄位掛一個自訂的
    deserializer（負責把 JSON 轉成 Java 物件的類別）。
  - 會不會影響其他地方：這是全域設定，但影響範圍只有 API 的請求內容：
    - 網頁表單走 Spring 的資料綁定，不經過 Jackson。
    - 行情 client 用 readTree 讀成樹狀結構，coercion 規則不會套用。
    - 現有測試會一起跑，確認沒有被影響。
  - 不認得的欄位：請求 DTO 明確加上 @JsonIgnoreProperties(ignoreUnknown = 
    true)，不依賴預設值。
  - 超過兩位小數：Jackson 解析成 BigDecimal 會保留原文，所以 980.555
    不會被四捨五入成 980.56，交給 @Digits(fraction = 2) 擋下。
  - 其他檢查規則：和網頁表單相同，包括 @NotNull、張數 1～999、買進價大於
    0。代號在 record 的建構子裡先去掉前後空白，再交給 @NotBlank 和 @Pattern
    檢查，和網頁一樣。

  為什麼 404、405 要另外寫一個 handler：

  - 這兩種錯誤發生在 Spring「選 controller」的階段，那時還不知道是哪個
    controller。
  - 所以只套用在 api 套件的 @RestControllerAdvice(basePackages = ...)
    接不到這兩種錯誤。
  - 因此另外寫一個全域的 handler，只認 /api/
    開頭的路徑；其他路徑把例外原樣丟回，交給 Spring 預設處理，網頁的 404 照舊。
  - 測試會同時確認「網頁 404 沒有變成 JSON」。

  Content-Type 錯誤一定接得到：請求的 Content-Type
  不對時，例外是在讀取請求內容時才丟出，那時已經選好 controller，所以
  ApiExceptionHandler 接得到。為了這一點，POST 和 PUT 刻意不寫
  consumes；寫了的話，這個錯誤會提早在選 controller 時發生。

  - 我確認過，application.properties 裡沒有設定 default-property-inclusion。
  - 測試會用 jsonPath(...).value(nullValue()) 搭配
    exists()，同時確認「欄位存在」而且「值是 null」。

  陷阱 4：name、market 不能是 null

  - name：現有查詢已經寫了 coalesce(h.name, 
    q.name)，也就是持股沒有名稱時改用行情快取的名稱；兩邊都沒有時，API 輸出
    ""（空字串）。
  - market：建議分兩層：
    a. 查詢改成 coalesce(h.market,

  陷阱 5～8

  - 5. 價格輸出成數字：DTO 欄位型別是 BigDecimal，Jackson 會輸出成數字。測試用

  - 6. price_date 的來源：用 closeDate，也就是「最近一個有成交日」，和

  定，看哪些測試失敗，做完再還原。
