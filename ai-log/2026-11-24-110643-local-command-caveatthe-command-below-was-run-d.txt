  - 所以亂碼是打開它的編輯器用錯編碼在顯示，不是檔案內容有問題。

  最可能的原因（有把握，但還沒確認你用的是哪個編輯器）
  這個專案目錄裡有 Eclipse 的設定檔，所以你應該是用 Eclipse 開的。
  - Eclipse 對 .properties 檔有一個獨立的預設編碼
    ISO-8859-1（只認得英文字母的舊編碼）。
  - 這個預設會蓋過你在專案上設定的 UTF-8，所以 UTF-8 的中文就被顯示成亂碼。
  - Java 檔和 HTML 檔不受這個預設影響，所以只有 .properties 會出問題。

  修正方法（在 Eclipse 裡設定一次，以後所有專案都適用）
  1. 打開 Window → Preferences → General → Content Types。
  2. 在右邊的樹狀清單點開 Text，選 Java Properties File。
  3. 下方的 Default encoding 填 UTF-8，按 Update，再按 Apply and Close。
  4. 把 application.properties 關掉，再重新打開，中文應該就正常了。

  注意
  - 修正之前，不要在 Eclipse 裡存檔這個亂碼畫面。一存檔，亂碼就會真的寫進檔案，
    到時候我得重寫一次。如果已經存過了，跟我說，我再修。
